# Aura Flow releases

Downloads for **Aura Flow** (voice dictation for Windows) and **Aura Voice Commander** (voice commands for games).

The apps check this repository once a day for updates and install them themselves, so there is usually nothing to do here.
Every update is digitally signed, and the apps refuse anything that isn't.

Installers are under [Releases](../../releases). There is no source code in this repository.
